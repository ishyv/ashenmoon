# Ashenmoon Design Pack — Milestone 2: First Camp

This pack extends the earlier Ashenmoon design documents with the next practical content milestone.

Milestone 1 focused on proving the player can exist in the world: gathering, early survival, combat foundations, UI panels, item handling, and first interactions.

Milestone 2, **First Camp**, focuses on making the first 10–20 minutes feel like a real survival game instead of a combat sandbox with loose resources.

## Core Milestone Promise

The player begins with almost nothing, finds a place to survive, builds a minimal camp, learns that materials can be processed into useful things, and starts to understand that the forest is not static decoration.

## Design Maxims Reaffirmed

```txt
Definitions describe.
Systems execute.
State records.
UI displays.
Pixi renders.
Tests protect.
```

```txt
The player should be able to try things before knowing the recipe.
A discovered recipe is a shortcut and memory aid, not permission from the game.
```

```txt
Events should happen through the world, not through title cards.
A wolf howl is audio. A bird flock is motion. Rain is weather. Do not announce the obvious like a nervous tutorial goblin.
```
