# 25 — Scope and Non-Goals for First Camp

## Purpose

First Camp must stay focused.

This milestone should make survival/crafting/world interaction work in one strong forest area.

It should not become the whole game.

## In Scope

- one strong forest biome
- campfire
- primitive work surface
- drying rack
- crude shelter
- marker/sign
- crafting discovery foundation
- unknown recipe crafting
- discovered recipe shortcuts
- basic processing chains
- rabbits/deer/boars/wolves
- simple animal behaviors
- wolf howls
- animal-vs-animal events
- bird flock reveal
- rain
- cold/dark first night

## Out of Scope

### Full NPC System

NPCs are important later, but not for this milestone.

Do not implement:

- recruitable NPCs
- full dialogue trees
- camp workers
- traders
- betrayal systems
- complex relationship state

NPCs can be designed later as their own milestone.

### Explicit Quest System

Do not build quest logs or objective checklists for First Camp.

Ashenmoon should prefer implicit goals:

- thirst
- cold
- darkness
- danger
- discovered knowledge
- camp needs

### Dropped Item Ecology

Dropped items should become core later, but not yet.

Do not implement:

- animals attracted to every dropped food
- item theft by scavengers
- advanced item decay networks
- contamination chains
- weather moving items

These need more item/content density first.

### Advanced Worldgen

Do not build multiple biomes yet.

No:

- swamp biome
- cave biome
- ruined village edge
- large map regions
- faction territory

Build one strong forest first.

### Complex Body Simulation

Do not implement detailed body parts yet.

Keep early statuses simple:

- cold
- sickness
- poison
- cut/bleeding
- exhaustion

### Advanced Animal Senses

Do not implement sound/smell investigation yet.

Allowed:

- detection radius
- flee radius
- attack/threat radius
- fire avoidance radius

Later:

- smell trails
- noise investigation
- bait
- tracks

### Overbuilt Crafting UI

Do not build a giant crafting spreadsheet.

The system should support:

- experimentation
- station context
- discovered recipes
- recipe shortcut list
- meaningful feedback

Not:

- huge MMO crafting panel
- hundreds of placeholder recipes
- silent combine buttons

## Scope Warning

The milestone fails if it ships 50 half-working mechanics instead of 10 connected ones.

Connected survival beats matter more than content count.

A campfire that warms, cooks, boils, scares animals, and changes night survival is worth more than fifteen decorative items named Damp Root Variant C.
