# Feedback / Juice Checklist

Use this when a player action or game event is implemented.

## General

- [ ] Player can identify the interactive/actionable object.
- [ ] Action start is visible or audible.
- [ ] Action progress is visible if it takes time.
- [ ] Action success is visible or audible.
- [ ] Action failure is understandable.
- [ ] World state changes visibly if relevant.
- [ ] UI state updates if relevant.
- [ ] Feedback timing matches the actual state change.

## Combat

- [ ] Hit reaction.
- [ ] Hit VFX.
- [ ] Hit SFX.
- [ ] Damage number/health change.
- [ ] Attack cooldown/recovery clarity.
- [ ] Death feedback.
- [ ] Miss/block/immune feedback if relevant.

## Gathering

- [ ] Target highlight or prompt.
- [ ] Gathering animation.
- [ ] Progress/tick feedback.
- [ ] Particle effect.
- [ ] Start/tick/success sound.
- [ ] Inventory/resource UI update.
- [ ] Node depletion visual.

## UI

- [ ] Hover/focus/selected states.
- [ ] Disabled state.
- [ ] Loading/progress state if relevant.
- [ ] Error state.
- [ ] Success state.
